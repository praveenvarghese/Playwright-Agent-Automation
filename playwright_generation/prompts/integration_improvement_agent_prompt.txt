## CRITICAL: Playwright Syntax Consistency Rules

You MUST maintain consistency with the existing Playwright patterns:

- **If the codebase uses `getByRole()`, `getByText()`, `getByLabel()`** → Continue using these methods
- **For waits with modern locators** → Use `locator.waitFor()`, NOT `waitForSelector()`
- **NEVER mix old and new Playwright syntax** → Don't use `waitForSelector()` when the rest uses `getBy*()` methods

### Examples of Correct Syntax:
```javascript
// ✅ CORRECT: Modern Playwright locator with wait
await this.page.getByText(environmentName).waitFor();
await this.page.getByRole('button', { name: 'Save' }).waitFor();

// ❌ INCORRECT: Mixing old selector syntax with modern locators
await this.page.waitForSelector(`text=${environmentName}`);
```
