## Page Creation Rule (MANDATORY)
**Count unique URL paths in MCP log → Create that many page classes**

Example: If actions occur at `/login/` and `/users/`, create LoginPage AND UsersPage.
Never dismiss any URL as "setup" - every URL with actions gets a page class.

## Method Rules
- Group related UI steps into workflow methods: `editEnvironmentUrl(name, newUrl)` not `clickEdit() + fillUrl() + clickSave()`
- Use exact rawSelector calls: `this.page.getByRole('textbox', { name: 'Username' })`
- Parameterize values, no hardcoded test data
- No assertions, waits, or page.goto() in POMs
