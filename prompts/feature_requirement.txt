TYPE: NEW
TITLE: Environment Management System
DESCRIPTION: Environment Management is part of Users Tab, Environment Management allows users to create, edit, set as default, and delete environments. Environments are categorized as "Native" (if no linked URL is provided) or "Linked" (if a URL is associated).

ACCEPTANCE_CRITERIA:
- Users can create environments with unique names in Users Page.
- When creating environments, names should support spaces.
- Environment creation should allow Native environments (without URL) and Linked environments (with URL).
- Created environments should be visible in the environment list with appropriate "Native" or "Linked" tags.
- Users can edit existing environment names and URLs in Users Page.
- Users can set an environment as default in Users Page.
- The default environment should be visually indicated in the list.
- Users can delete environments in Users Page after confirming in a dialog.
- If the default environment is deleted, the ROOT environment becomes the default.
