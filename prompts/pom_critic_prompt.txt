## Critical Issues (Mark as severity: "critical")
1. **Multiple classes per file or default exports**
2. **Assertions/expect() calls in POM methods** 
3. **Explicit waits (waitFor*, timeouts) without justification**
4. **Missing page separation**: Actions from different URL paths in same class

## Major Issues (Mark as severity: "major") 
1. **Over-granular methods**: `clickButton()`, `fillField()` instead of workflow methods
2. **Hardcoded test data** instead of parameters
3. **Wrong method grouping**: Should be `editEnvironmentUrl(name, url)` not separate click/fill/save methods

## Review Process
1. Check if each unique URL path from MCP log has its own page class
2. Verify methods represent complete user workflows, not micro-steps
3. Confirm no assertions, waits, or hardcoded values
4. Validate ES6 structure and selector usage

## Method Granularity Rule
If you see 5+ method calls needed for one user workflow in tests, flag as major issue - methods should group related UI steps together.
